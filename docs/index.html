FAQ

Questions

Is it really free?

Yes. It’s open source under the MIT license, with no paid tier, no trial and no account. You only pay for the AI tools you already use, like Claude Code.

Do I have to change how I work?

No. It’s the real Claude Code, so your CLAUDE.md, skills, hooks and MCP servers carry over. Your repo stays as it is, and a full terminal is one tab away.

What do I need?

A Mac on macOS 26, plus Claude Code. Xcode 26 with an iOS simulator runtime is only needed for the simulator. Setup checks each one and installs what it can.

Does it work with Codex?

Yes. The terminal runs any agent CLI, and Vibex registers its MCP server and skill with Codex as well as Claude Code. AI Usage reads Codex’s limits too.

What can it run?

iOS and macOS apps from Xcode or XcodeGen, web apps with a dev server (npm, pnpm, yarn or bun), and Swift, Rust and Go command-line projects. Anything else runs in the terminal like always.

Is my code sent anywhere?

Vibex sends your code nowhere itself. Claude Code talks to Anthropic as it always does, and usage numbers come from local logs. Vibex contacts GitHub for updates, and skills.sh and the MCP registry when you browse them.

How does it update?

Vibex checks GitHub releases in the background and offers the new version in its own window, or you can run the install command again.
