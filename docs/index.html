Questions

Is Vibex really free?
Yes. It's open source under the MIT license, with no paid tier, no trial and no account. You only pay for the AI tools you already use, like Claude Code.
What do I need?
A Mac on macOS 26 (Apple silicon or Intel), Xcode 26 with an iOS simulator runtime for the simulator pane, and Claude Code. Setup checks each one and installs what it can.
Does it work with Codex or other agents?
The terminal runs anything. The built-in MCP server works with any MCP client, and the AI Agents dashboard reads Codex's usage limits too.
Is my code or usage sent anywhere?
No. Usage numbers come from Claude Code's and Codex's local logs. Vibex only talks to GitHub to check for updates and to skills.sh when you browse skills.
Why does macOS warn me when I first open it?
Vibex isn't notarized yet. The install script handles it; with the DMG, open System Settings → Privacy & Security and click Open Anyway.
How do updates work?
Vibex checks GitHub releases in the background and installs the new version when you quit, or right away with Restart to Update.
